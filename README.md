# Login Form GUI

A simple Java Swing application with username and password fields. 
Enter credentials and click Login to see a success or error message.

## Built With
- Java
- Swing (JFrame, JTextField, JPasswordField, JButton, JOptionPane)

## How to Run
1. Compile: `javac WorkingGUI.java`
2. Run: `java WorkingGUI`

## What I Learned
- Building a GUI with Swing components
- Using layout with setBounds and absolute positioning
- Handling button clicks with ActionListener
- Reading and comparing user input
- Showing dialogs with JOptionPane
